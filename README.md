# Prediksi Risiko Karhutla Kalimantan Timur

Prediksi probabilitas munculnya hotspot kebakaran hutan dan lahan (karhutla) per sel grid
0,05° di Provinsi Kalimantan Timur untuk satu minggu ke depan.

Proyek ini masih dalam tahap awal. Dokumentasi lengkap akan ditambahkan seiring pengembangan.

## Menjalankan

```bash
make setup   # buat environment dengan uv
make lint    # ruff
make test    # pytest
```

> Disclaimer: ini proyek portofolio, bukan sistem peringatan dini resmi.
